타임라인

    설정
    외형 소스 알림 순찰 주기 수집·보관 쓰기 액션 아카이브 Claude

    외형

    테마와 홈 화면 카드 배치.

    테마
    고르면 바로 미리 보여 줘 — 저장을 눌러야 유지돼. 시스템은 macOS 라이트/다크를 따라가.
    홈 카드 배치 넓은 화면에선 홈에서 패널 머리(⠿)·모서리를 끌어 옮기고 크기를 바꿔 — 놓으면 바로 저장돼.
    여기서 순서(↑/↓)·폭(1열/2열)을 바꿔 저장하면 그 순서로 다시 짜. 좁은 화면에선 위→아래 한 줄씩.
    링크 열기
    Slack·Figma·Notion 링크를 브라우저 대신 설치된 앱으로 열어(중간 "앱에서 열기" 탭이 안 남아). 앱이 없으면 웹으로. ⌘-클릭은 늘 웹.
    Slack 앱 → 워크스페이스 이름 → 워크스페이스 설정 URL 또는 about 에서 T… ID. 비우면 Slack 링크는 웹으로 열려.
    워크스페이스 주소의 <이름>.slack.com 에서 <이름>. 넣으면 그 워크스페이스 링크만 앱으로(다른 워크스페이스는 웹), 비우면 모든 *.slack.com.

    소스

    순찰·아침 브리핑·홈 agenda 가 읽는 업무 신호. 끈 소스는 조회도 보고도 안 해.

    Slack

    Slack 소스가 꺼져 있어 — 값은 그대로 보존돼

    엔터(또는 쉼표)로 추가, ✕ 로 빼기. 후보는 지금까지 본 채널에서 골라 줘.

    팔로업 채널
    SLACK 채널
    멘션이 없어도 따라가 볼 채널. 홈에 채널별 24시간 요약을, 순찰은 할 일·업데이트를 올려.
    트래킹 제외 채널
    SLACK 채널
    순찰·브리핑·홈 agenda 에서 조회도 보고도 안 해. 팔로업 채널보다 우선.
    답 필요 해제 이모지
    SLACK 이모지
    내 답글이 있거나 이 이모지로 리액션한 메시지는 '확인 필요'에서 빠져. 최대 8개, 다 빼면 리액션은 안 봐.
    앞에서부터 N개만 검색(기본 3). 답 필요 후보가 없으면 검색 안 해.
    그룹 멘션
    SLACK 그룹
    내가 속한 유저그룹(@팀) 멘션도 모아. 그룹 ID(S…, 그룹 프로필의 ⋯ → ID 복사) 또는 핸들. 최대 8개, 그룹마다 검색 1번 추가. 답 필요에는 그룹에 구체적으로 물은 것만.

    순찰 주기

    Ned 가 얼마나 자주 둘러보고 홈을 새로 고칠지, 언제 아침 브리핑을 할지.

    세션 이벤트가 없을 때 LLM 으로 업무 신호를 보는 최소 간격
    소스 목록·2시간 내 일정·스레드 새 답글·세션 알림이 지난 순찰 그대로면 자동 순찰은 Claude 를 부르지 않아. 아침 브리핑·지금 점검은 늘 실행.
    홈 agenda(일정·Slack·메일·Jira·GitHub)를 다시 읽는 주기. 아래 소스별 칸을 비우면 이 값을 따라.
    소스별 주기 (분)
    조용한 시간 동작
    알림의 조용한 시간과 같은 시간대. 자동 순찰·홈 갱신만 바뀌고, 수동 새로고침·지금 점검은 늘 바로 돌아. 끝나면 전 소스를 한 번 새로 읽어.
    유휴 시 동작
    분 활동 없고 회 연속 변화 없으면
    활동 = 대시보드 사용 · Claude Code 세션 · Mac 키보드/마우스 입력. 다시 활동하면 바로 풀리고 전 소스를 한 번 새로 읽어.

    수집·보관

    Ned 는 소스를 가져올 때 새로 온 것만 읽고(증분), 본 항목을 이력으로 보관해. 카드·순찰·초안은 그 이력에서 표시 구간만큼 보여 줘. Claude 호출 없이 데몬이 디스크에만 써.

    표시 구간
    시간 (1~168)일 (1~14)
    수집 창
    시간 (1~168, 기본 24 — 첫 수집·6시간마다 다시 볼 범위, 평소엔 지난 수집 이후만. 표시 구간보다 짧으면 표시 구간으로 맞춤)
    보관 기간
    일 (0~365, 0 = 기록 안 함 — 표시 구간보다 짧으면 표시 구간에 맞춰 늘려)
